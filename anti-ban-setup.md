## Setup Steps

### 1. AdsPower Setup
1. Download from https://www.adspower.com/download
2. Create account (can use email)
3. Start with free plan (2 profiles) to test
4. Upgrade to paid when ready

### 2. IPRoyal Setup
1. Sign up at https://iproyal.com/
2. Purchase residential proxy package
3. Get proxy credentials (host:port:user:pass)

### 3. Create Profiles in AdsPower
For each character:
1. Create new browser profile
2. Assign unique proxy
3. Set unique fingerprint settings
4. Name profile after character (mia, jordan, etc.)

### 4. Create Instagram Accounts
For each profile:
1. Open profile in AdsPower
2. Go to Instagram
3. Sign up with unique email
4. Complete profile setup

## Email Strategy for 20 Accounts

## Account Creation Schedule

Don't create all 20 at once - looks suspicious.

**Week 1:** Create 5 accounts (1 per day)
**Week 2:** Create 5 more
**Week 3:** Create 5 more
**Week 4:** Create final 5

Let each account "age" a few days before heavy activity.

---

## Daily Limits (Stay Safe)

Per account per day:
- Follows: 20-50 (start low, increase over time)
- Likes: 50-100
- Comments: 10-20
- Posts: 1-3
- DMs: 10-20

New accounts should start at the LOW end of these ranges.
